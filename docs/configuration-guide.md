# Configuration Guide — OpenMRS CCE Receiver Adaptor

## Spring Profiles

| Profile | YAML file | Purpose |
|---------|-----------|---------|
| `default` | `application.yml` | Base config with sensible defaults |
| `local` | `application-local.yml` | Local dev — DEBUG logging, security disabled |
| `staging` | `application-staging.yml` | Pre-production — INFO logging |
| `production` | `application-production.yml` | Production — WARN root, security enabled |

```bash
./gradlew bootRun --args='--spring.profiles.active=local'
```

## Configuration Reference

### Server

| Property | Env Var | Default | Description |
|----------|---------|---------|-------------|
| `server.port` | `SERVER_PORT` | `8080` | HTTP port |
| `server.shutdown` | — | `graceful` | Graceful shutdown |
| `spring.lifecycle.timeout-per-shutdown-phase` | `SHUTDOWN_TIMEOUT` | `30s` | Shutdown wait |

### OpenMRS REST Connection (Primary)

| Property | Env Var | Default | Description |
|----------|---------|---------|-------------|
| `openmrs.rest.base-url` | `OPENMRS_REST_BASE_URL` | `http://localhost:9096/openmrs/ws/rest/v1` | OpenMRS REST API base URL |
| `openmrs.rest.timeout` | `OPENMRS_REST_TIMEOUT` | `10000` | HTTP timeout (ms) |

### OpenMRS FHIR Connection (Fallback)

| Property | Env Var | Default | Description |
|----------|---------|---------|-------------|
| `openmrs.fhir.base-url` | `OPENMRS_FHIR_BASE_URL` | `http://localhost:9096/openmrs/ws/fhir2/R4` | OpenMRS FHIR API base URL |
| `openmrs.fhir.timeout` | `OPENMRS_FHIR_TIMEOUT` | `10000` | HTTP timeout (ms) |

### OpenMRS Authentication (Outbound)

| Property | Env Var | Default | Description |
|----------|---------|---------|-------------|
| `openmrs.auth.type` | `OPENMRS_AUTH_TYPE` | `basic` | `basic` or `oauth2` |
| `openmrs.auth.username` | `OPENMRS_AUTH_USERNAME` | `admin` | Username (for basic) |
| `openmrs.auth.password` | `OPENMRS_AUTH_PASSWORD` | `Admin123` | Password (for basic) |
| `openmrs.auth.oauth2.token-url` | `OPENMRS_AUTH_OAUTH2_TOKEN_URL` | — | OAuth2 token endpoint URL |
| `openmrs.auth.oauth2.client-id` | `OPENMRS_AUTH_OAUTH2_CLIENT_ID` | — | OAuth2 client ID |
| `openmrs.auth.oauth2.client-secret` | `OPENMRS_AUTH_OAUTH2_CLIENT_SECRET` | — | OAuth2 client secret |
| `openmrs.auth.oauth2.scope` | `OPENMRS_AUTH_OAUTH2_SCOPE` | — | OAuth2 scope (optional) |

### Inbound API Security

| Property | Env Var | Default | Description |
|----------|---------|---------|-------------|
| `cce.security.enabled` | `CCE_SECURITY_ENABLED` | `false` | Enable inbound token validation |
| `cce.security.token` | `CCE_SECURITY_TOKEN` | — | Pre-shared bearer token (generated by adaptor, shared to CCE Intelligence Service for adaptor registration) |
| `cce.security.username` | `CCE_SECURITY_USERNAME` | `cce-client` | Basic auth username (fallback if token not set) |
| `cce.security.password` | `CCE_SECURITY_PASSWORD` | `changeme` | Basic auth password (fallback if token not set) |

### Identifier Configuration

| Property | Env Var | Default | Description |
|----------|---------|---------|-------------|
| `openmrs.identifier.type-name` | `OPENMRS_IDENTIFIER_TYPE_NAME` | `OpenMRS ID` | Primary identifier type name |
| `openmrs.identifier.location-uuid` | `OPENMRS_IDENTIFIER_LOCATION_UUID` | *(auto-discovered)* | Location UUID for identifiers |
| `openmrs.identifier.idgen-source-uuid` | `OPENMRS_IDENTIFIER_IDGEN_SOURCE_UUID` | *(auto-discovered)* | Idgen source UUID |

### Capability Refresh

| Property | Env Var | Default | Description |
|----------|---------|---------|-------------|
| `openmrs.capability-refresh-ms` | `OPENMRS_CAPABILITY_REFRESH_MS` | `21600000` | Config re-discovery interval (6 hours) |

### Logging

| Property | Env Var | Default | Description |
|----------|---------|---------|-------------|
| `logging.level.org.openphc.cce` | `LOG_LEVEL_APP` | `DEBUG` | Application log level |
| `logging.level.root` | `LOG_LEVEL_ROOT` | `INFO` | Root log level |

### Actuator

| Property | Default | Description |
|----------|---------|-------------|
| `management.endpoints.web.exposure.include` | `health,info,prometheus,metrics` | Exposed actuator endpoints |
| `management.endpoint.health.show-details` | `when-authorized` | Health detail visibility |
| `management.endpoint.health.probes.enabled` | `true` | Liveness/readiness probes |

## Auto-Discovery

The following values are **auto-discovered** from OpenMRS at startup and do not need manual configuration. Override only if auto-discovery fails.

| Config | Discovered From | API Endpoint |
|--------|-----------------|-------------|
| Location UUID | Login Location tag | `GET /location?tag=Login+Location` |
| Identifier Type UUID | Matching `type-name` | `GET /patientidentifiertype` |
| Source Identifier Types | All non-primary types | `GET /patientidentifiertype` |
| Idgen Source UUID | Primary type source | `GET /idgen/identifiersource` |
| Visit Type UUID | "Facility Visit" preferred | `GET /visittype` |
| Encounter Types | All encounter types | `GET /encountertype` |
| Person Attribute Types | Phone Number, Email UUIDs | `GET /personattributetype` |

## Example: Local Development

```bash
SERVER_PORT=8080
OPENMRS_REST_BASE_URL=http://localhost:9096/openmrs/ws/rest/v1
OPENMRS_FHIR_BASE_URL=http://localhost:9096/openmrs/ws/fhir2/R4
OPENMRS_AUTH_TYPE=basic
OPENMRS_AUTH_USERNAME=admin
OPENMRS_AUTH_PASSWORD=Admin123
CCE_SECURITY_ENABLED=false
LOG_LEVEL_APP=DEBUG
```

## Example: Production

```bash
SERVER_PORT=8080
OPENMRS_REST_BASE_URL=http://openmrs:8080/openmrs/ws/rest/v1
OPENMRS_FHIR_BASE_URL=http://openmrs:8080/openmrs/ws/fhir2/R4
OPENMRS_AUTH_TYPE=basic
OPENMRS_AUTH_USERNAME=cce-receiver
OPENMRS_AUTH_PASSWORD=${SECRET_OPENMRS_PASSWORD}
CCE_SECURITY_ENABLED=true
CCE_SECURITY_TOKEN=${SECRET_CCE_TOKEN}    # Pre-shared token for adaptor registration
OPENMRS_IDENTIFIER_TYPE_NAME=OpenMRS ID
LOG_LEVEL_APP=INFO
LOG_LEVEL_ROOT=WARN
```

## Example: Production with OAuth2 (Outbound to OpenMRS)

```bash
# Outbound — OpenMRS auth via OAuth2
OPENMRS_AUTH_TYPE=oauth2
OPENMRS_AUTH_OAUTH2_TOKEN_URL=https://keycloak.example.org/realms/openmrs/protocol/openid-connect/token
OPENMRS_AUTH_OAUTH2_CLIENT_ID=cce-receiver-service
OPENMRS_AUTH_OAUTH2_CLIENT_SECRET=${SECRET_OAUTH2_CLIENT_SECRET}
OPENMRS_AUTH_OAUTH2_SCOPE=openid

# Inbound — pre-shared token for adaptor registration
CCE_SECURITY_ENABLED=true
CCE_SECURITY_TOKEN=${SECRET_CCE_TOKEN}

# OpenMRS endpoints
OPENMRS_REST_BASE_URL=http://openmrs:8080/openmrs/ws/rest/v1
OPENMRS_FHIR_BASE_URL=http://openmrs:8080/openmrs/ws/fhir2/R4
```

## Complete application.yml Reference

```yaml
server:
  port: 8080
  shutdown: graceful

spring:
  application:
    name: cce-receiver-adaptor
  lifecycle:
    timeout-per-shutdown-phase: 30s

cce:
  security:
    enabled: false
    token:                    # Pre-shared bearer token (from CCE_SECURITY_TOKEN env var)
    username: cce-client      # Basic auth fallback
    password: changeme

openmrs:
  rest:
    base-url: http://localhost:9096/openmrs/ws/rest/v1
    timeout: 10000
  fhir:
    base-url: http://localhost:9096/openmrs/ws/fhir2/R4
    timeout: 10000
  auth:
    type: basic
    username: admin
    password: Admin123
    oauth2:
      token-url:
      client-id:
      client-secret:
      scope:
  capability-refresh-ms: 21600000
  identifier:
    location-uuid:
    idgen-source-uuid:
    type-name: OpenMRS ID

management:
  endpoints:
    web:
      exposure:
        include: health,info,prometheus,metrics
  endpoint:
    health:
      show-details: when-authorized
      probes:
        enabled: true
  metrics:
    tags:
      application: cce-receiver-adaptor

logging:
  level:
    root: INFO
    org.openphc.cce: DEBUG
  pattern:
    console: "%d{ISO8601} [%thread] %-5level %logger{36} [%X{correlationId:-}] [%X{source:-}] [%X{resourceType:-}] - %msg%n"
```
